# 自动化工厂流水线模拟游戏

一款**自动化工厂流水线**模拟游戏：采集矿石、冶炼金属、组装零件、研发科技、建造火箭并发射卫星。纯原生 **JavaScript + Canvas** 实现，零外部依赖，打开浏览器即可游玩。

## 快速开始

- **方式一（推荐）**：直接双击 `index.html`，浏览器中即可游玩。
- **方式二**：在项目目录下启动本地静态服务后访问，例如：

  ```bash
  python -m http.server 8000
  # 然后浏览器打开 http://localhost:8000
  ```

> 存档保存在浏览器 localStorage 中（3 个手动槽位 + 1 个自动槽位），也支持导出/导入 JSON 存档文件。

## 玩法目标

从零开始搭建一座自动化工厂：

1. **开采**：在铁矿/铜矿/煤矿脉上放置矿机，水域旁放水泵，油田上放抽油机。
2. **运输**：用传送带与机械臂把矿石送入熔炉，把产物送往组装机。
3. **生产**：熔炉冶炼矿石为金属板，组装机将零件加工成齿轮、电路板、发动机等，最终合成科学包。
4. **科研**：让实验室消耗科学包推进科技树，解锁更快的传送带、高级建筑与高级配方。
5. **通关**：研究「火箭科技」与「卫星发射」，生产火箭部件、火箭燃料与卫星，达成最终胜利目标。

## 资源链条

```
矿石 ──熔炉──> 金属板 ──组装机──> 零件（齿轮/铜线/电路板…）
零件 ──组装机──> 科学包（红/绿/蓝） ──实验室──> 科技解锁
原油+水 ──炼油厂──> 石油气/润滑油 ──化工厂──> 火箭燃料
```

共有 **24 种物品**（含 4 种流体）、**19 个配方**、**19 种建筑**、**11 个科技节点**。

## 核心系统

### 网格化地图
- 4 种程序化生成场景：**新手平原、沙漠油田、高山矿区、随机世界**。
- 可自定义尺寸（小/中/大）与随机种子；地形含草/沙/石/水，矿脉、油田随机分布。
- 支持多地图场景：每个存档独立保存整张地图的矿量与布局。

### 实时生产状态可视化
每个生产建筑有明确状态机：**生产中 / 缺料 / 堵塞 / 闲置 / 枯竭**。
- 按 `S` 在图上高亮所有建筑状态；
- 悬浮建筑显示配方进度、传送带载荷、管道液位、矿脉剩余储量。

### 科研科技树
- Canvas 绘制的科技树，支持拖拽、滚轮缩放、节点点击查看详情。
- 前置依赖系统：必须先完成前置科技才能开始后续研究。
- 未解锁的建筑在工具栏中置灰，点击可跳转科技树定位对应科技。

### 生产统计面板
- 每秒采样，保留 240 秒历史数据，绘制产出/消耗双系列曲线。
- 30 秒速率窗口实时计算各项资源速率。
- **瓶颈自动检测**：消耗大于产出的资源列为瓶颈并高亮提示。

### 存档 / 读档
- 3 个手动槽位 + 自动存档（每 60 秒）。
- 完整序列化：地图、矿量、建筑、传送带物品（含转弯进料侧）、机械臂筛选/手持状态、合流调度游标、地面物料堆、管道流体、研究进度、统计数据。
- 支持导出/导入 JSON 存档，方便备份与分享。

## 技术架构

纯原生 JS，无任何框架与依赖，`<script>` 标签顺序加载，兼容 `file://` 协议直接打开。

```
index.html          页面骨架与脚本加载入口
css/style.css       暗色工厂主题样式
js/core/            配置与工具（事件总线、固定步长仿真）
js/data/            数据定义：物品、配方、建筑、科技树、地图预设
js/game/            核心逻辑：地图、仿真、科研、统计、存档、游戏主类
js/ui/              渲染器与各 UI 面板（工具栏/信息/统计/科技树/弹窗/顶栏）
js/main.js          启动引导：输入处理、主循环
```

### 仿真核心
- 固定步长仿真：每秒 20 tick，支持 0.5×~4× 速度倍率。
- 传送带物品流：每格容量 4，物品沿**直行/转弯折线路径**平滑移动、尾部对齐进料。
- **转弯与多路汇入**：任意传送带都可从背部/左侧/右侧三个方向汇入（正面顶头不行），目标带按轮转（round-robin）在各上游间公平调度，合流不会饿死某一侧。
- **统一拥堵处理**：每个 tick 重置「入口占用表」，合流与机械臂共用同一入口容量检查，在途物品（带面、机械臂手上）天然占位，杜绝抢料与重复放入。
- 机械臂：从身后格抓取、向前方格放置，支持 1/2 格范围；可设置**物品筛选条件**与**按需供给**。
- **按需物流调度（需求数量 × 在途预留联动）**：开启按需供给的机械臂不再做「缺料才抓」的粗放判断，而是每 tick 先于机械臂运行统一调度器：
  - **需求数量**：每个熔炉/组装机/化工厂/炼油厂/实验室按当前配方算出目标缓冲（生产建筑约 2 轮份、实验室约 1 个消耗周期），净需求 = 目标 − 槽内已有。
  - **在途预留**：带面物品与机械臂手持物品带「预留章」（`resv=消费者`）。调度器沿供料带反向追踪，把无主在途物品按净需求预打标给消费者；按需机械臂只搬运净需求尚未被在途覆盖的物品，从源头杜绝过量供给。
  - **供料优先级**：消费者建筑可设置**高/普通/低**三档优先级（按生产线）。多个消费者争同一条带时，高优先级生产线先补足在途预留，同级按 tick 轮转（round-robin）公平分配，不饿死任何一侧；共享箱/堆料源的直供臂同样按优先级配额。
  - **环路安全**：带圈/岔路用 visited 集合 + 追踪深度收敛，不死循环；无净需求即完全不注入，物品不会在环里空转堆积；物品流过供料点进入死路/岔路后自动释放预留，供其他缺料消费者重新认领。
  - **配方切换**：预留随当前配方每 tick 重判，切换后旧原料章立即释放、机械臂改供新配方；切换瞬间抓在手里的旧料作为残留料放回残留槽，不卡死机械臂。
  - **拆建释放**：拆除消费者/机械臂后其预留章下一 tick 全部释放，带网在途物品被新消费者接管，全图不残留悬空预留。
  - **存档恢复**：消费者稳定 ID（`cid`）、供料优先级、每个在途/手持物品的预留归属全部序列化，读档后调度无缝继续；兼容无这些字段的 1.1.0 旧存档（自动补登默认值）。
  - 预留可视化：带面上被预留的物品右上角按目标消费者优先级颜色显示小圆点；高/低优先级消费者建筑左上角有优先级色点。
- **物料保留**：切换配方不再清空旧槽位（残留物料标记显示，可被机械臂运走，且不阻塞新配方）；拆除建筑时传送带在途物品、机械臂手持物、槽位与箱子物料全部落到该格**地面物料堆**，原地重建建筑自动回收。
- **存档恢复调度状态**：地面物料堆、传送带物品位置/进料侧/**预留归属**、合流轮转游标、机械臂筛选/按需开关/手持物/计时、消费者 cid/**供料优先级**、管道液位与流体类型全部序列化，读档后流水线无缝继续。
- 管道流体：液位均衡扩散，生产建筑带缓冲罐推/拉。
- 配方驱动生产：输入/输出槽位 + 速度倍率 + 缺料/堵塞状态机。
